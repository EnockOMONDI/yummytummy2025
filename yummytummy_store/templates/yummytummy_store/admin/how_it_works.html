Session-Based Cart

Shopping cart data is stored in user sessions, allowing guests to shop without creating accounts. Cart persists across page visits and automatically converts to orders during checkout.

Auto Account Creation

Guest customers automatically get user accounts created during checkout. They receive email credentials and can track orders without manual registration.

M-Pesa Integration

Seamless mobile money payments through Safaricom M-Pesa STK Push. Real-time payment confirmation and automatic order status updates.

Product Variants

Products support multiple variants (sizes, weights) with different pricing. Customers can select variants through expandable product cards.

Complete Order Lifecycle Management

Full order tracking from payment to delivery with 8 distinct status stages. Automated email notifications at each stage and comprehensive admin interface for order management. Customers track progress through personalized dashboards with real-time updates.

Offline Order Management

Sales team can create orders for customers who prefer offline ordering. Complete workflow from order creation to payment confirmation with automatic email notifications and admin management.

Coupon System

Flexible discount system with percentage and fixed amount coupons. Usage tracking and expiration date management included.

Technical Payment Process Details

1

Payment Request Initiation

Customer Action: Selects M-Pesa and enters phone number (e.g., 0712345678)
System Process: Order created with status "pending", STK Push API called
File Location: views.py:587 (order creation), views.py:674 (STK Push)
Business Benefit: Automated payment processing reduces manual work

2

STK Push Success/Failure

Success Path: Order status updated to "processing" (views.py:685)
Failure Path: Order status set to "failed" with tracking status (views.py:692-700)
Customer Experience: Receives payment prompt on phone or error message
Business Benefit: Clear status tracking for all payment attempts

3

Customer Payment Authorization

Customer Action: Enters M-Pesa PIN to authorize payment
Safaricom Process: Validates PIN and processes payment securely
System Waiting: Order remains in "processing" status until callback
Business Benefit: Secure payment method reduces fraud risk

4

Payment Callback Processing

Success (ResultCode=0): Order status → "completed", tracking status → "payment_confirmed" (views.py:953-970)
Failure (ResultCode≠0): Order status → "failed", tracking status → "cancelled" (views.py:989-997)
Automatic Actions: Account creation, email notifications, order tracking begins
Business Benefit: Immediate order processing and customer onboarding

5

Post-Payment Automation

Account Creation: Auto-generated user account with secure credentials
Email Notifications: Welcome email with login details and order confirmation
Order Tracking: Customer can track progress through dashboard
Business Benefit: Complete customer onboarding without manual intervention
